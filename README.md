### 🚀 Projects

#### 💧 Nam Sa-ard Kiosk System — *team project*
A water-kiosk management system made up of three apps:
- **[Server](https://github.com/yellowman0000/AZERTY_namsa-ard_Server)**: NestJS backend that receives kiosk heartbeats and daily meter logs (Prisma · PostgreSQL · Docker)
- **[Client](https://github.com/Siraphat2549/AZERTY_namsa-ard_Client)**: Next.js kiosk status page that sends heartbeats and shows server connectivity
- **[Client Operator](https://github.com/Siraphat2549/AZERTY_namsa-ard_ClientOperator)**: operator app for daily water-volume and cash entries, with an offline queue, auto-sync, SHA-256 tamper checks and photo evidence

#### 🌡️ [Light-Aware Room Monitor](https://github.com/Siraphat2549/ProjectMid_IOT) — *IoT group project*
Stand-alone ESP32 monitor for light, temperature and humidity, with a TFT display, LED/buzzer alerts,
real-time clock timestamps and CSV logging to an SD card.
`C++` `ESP32` `Arduino`

#### 🎲 [Sheriff of Nottingham](https://github.com/Siraphat2549/Sheriff_of_nottingham)
Desktop version of the bluffing board game for 2–5 players, with AI players and saved game history.
`Python` `Pygame` `SQLite`

#### 🛍️ [OneBankKheow Store](https://github.com/Siraphat2549/One-Bankkheow) — *ITCS223 team project*
Full-stack e-commerce site inspired by Thailand's "20 Baht shops", with a REST API and a MySQL database.
